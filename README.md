# Clasificador de citas A, B y C

Herramienta web para auxiliar la clasificación de citas por documento en las categorías A, B y C (autocita). Está dirigida a investigadores, bibliotecarios y personas relacionadas con procesos de revisión bibliométrica.

## Uso local

No requiere instalación, servidor, base de datos ni API. Abre `index.html` en un navegador moderno.

## Publicación en GitHub Pages

1. Crea en GitHub un repositorio público llamado `clasificador-citas`.
2. Sube a la raíz del repositorio `index.html`, `styles.css`, `app.js` y `README.md`.
3. En el repositorio abre **Settings > Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama **main**, la carpeta **/(root)** y pulsa **Save**.
6. GitHub mostrará la dirección pública cuando termine la publicación.

La clasificación se ejecuta en el dispositivo del visitante. GitHub Pages no necesita recibir las referencias para procesarlas.

La herramienta es un apoyo y sus resultados deben revisarse, especialmente cuando las referencias contienen autores ambiguos, datos incompletos o errores tipográficos.
